# **App Name**: Gighive Lite

## Core Features:

- Gig Browser: User-friendly job/gig browsing interface with search and filter options.
- Student Profiles: Student profile creation and management.
- Gig Poster: Employer interface for posting and managing gig listings.
- AI Gig Suggestions: AI tool to generate personalized gig recommendations based on student skills and interests.
- Student Dashboard: Dashboard to track applications and active gigs.
- Applicant Management: Employer applicant management interface

## Style Guidelines:

- Primary color: Vibrant yellow (#FFB300) inspired by the bee and upward arrow, conveying energy and opportunity.
- Background color: Light gray (#F5F5F5) providing a clean, neutral backdrop to ensure readability and focus on content.
- Accent color: A lighter shade of yellow (#FFCA28) to highlight key interactive elements and calls to action.
- Body and headline font: 'Open Sans', a friendly and readable sans-serif for a clean, modern look.
- Simple, consistent icons in vibrant yellow to represent different job categories and actions.
- Clean and organized layout to facilitate easy navigation and readability, using a grid system for consistent alignment.
- Subtle transitions and animations with a slight 'buzzing' effect to reflect the bee theme, ensuring a smooth and engaging user experience without being distracting.
